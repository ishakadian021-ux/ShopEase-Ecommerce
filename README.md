# 🛒 ShopEase – E-Commerce Website

A responsive front-end e-commerce website built with **HTML, CSS, and JavaScript**.

## 🌐 Live Demo
Live Website:
`https://ishakadian021.github.io/ShopEase-Ecommerce/`

## ✨ Features
- Responsive navigation
- Hero and promotional section
- Product categories and product listing
- Product detail page with image gallery
- Quantity controls
- Shopping cart layout and order summary
- Newsletter form
- Mobile responsive design

## 📄 Pages
- `index.html` – Home page
- `products.html` – Product listing
- `product-detail.html` – Product details
- `cart.html` – Shopping cart

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
- Font Awesome
- Unsplash images

## 📂 Project Structure
```text
ShopEase-Ecommerce/
├── index.html
├── products.html
├── product-detail.html
├── cart.html
├── styles.css
├── script.js
└── README.md
```

## 🚀 Run Locally
1. Clone the repository:
```bash
git clone https://github.com/ishakadian021/ShopEase-Ecommerce.git
```
2. Open the project folder.
3. Open `index.html` in a browser.
